Tentang Sistem

Cara kerja, metode, dan dataset yang digunakan dalam sistem analisis daya simpan pisang.

Cara Kerja Sistem

1

Input Gambar

User mengunggah foto pisang ke sistem untuk diproses.

2

Klasifikasi

Sistem mengklasifikasikan varietas & kategori utama kematangan.

3

Evaluasi Detail

Analisis warna, tekstur kulit & persentase kematangan.

4

Estimasi Simpan

Estimasi daya simpan berdasarkan model prediksi per varietas.

Metode

Pendekatan hybrid menggabungkan tiga metode utama untuk menghasilkan estimasi daya simpan yang akurat.

Deep Learning (CNN)

Klasifikasi kematangan visual dari gambar pisang menggunakan Convolutional Neural Network.

Image Processing

Analisis warna (HSV) dan tekstur kulit pisang untuk evaluasi detail kematangan.

Regression Model

Estimasi numerik daya simpan berdasarkan stage kematangan dan varietas pisang.
